# Escopo do protótipo

## Objetivo

Representar visualmente a aplicação LEM completa antes de novas alterações de implementação, preservando a linguagem visual e os fluxos já existentes.

## Telas previstas

1. Entrada: login e criação de conta.
2. Visão geral do dashboard.
3. Detalhes de um dispositivo — sistema e telemetria.
4. Detalhes de um dispositivo — arquivos, pacotes e saves.
5. Notas e anexos do dispositivo.
6. Gestão Docker.
7. Auditoria de segurança.
8. Histórico de telemetria.
9. Central de notificações e caixa de entrada.
10. Estados vazios, carregamento, erro e confirmação de ações destrutivas.
11. Layout mobile do dashboard.

## Critérios

- Desktop web responsivo, com prioridade para 1440 × 960.
- Componentes, cores, tipografia e densidade baseados no projeto atual.
- Cada fluxo importante deve mostrar pelo menos um estado normal e, quando aplicável, um estado de feedback.
- O protótipo é para avaliação visual e refinamento; não é código de produção.
- O entregável editável é `lem-dashboard.fig`, formato nativo suportado pelo OpenPencil.
