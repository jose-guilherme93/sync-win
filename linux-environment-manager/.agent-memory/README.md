# Agent Memory

This directory stores reviewable, durable project memory for Linux Environment Manager.

- `project/` — stable project context.
- `context/` — current work and handoff state.
- `decisions/` — rationale for technical choices.
- `sessions/` — concise records of meaningful work sessions.
- `conventions/`, `feedback/`, `references/`, `user/` — reserved categories for future use.

Do not store credentials, tokens, private keys, or sensitive personal data. Keep `AGENTS.md` as the canonical development instruction file.
